## 📖 專案特色

1. **8 種不重複科學原理機構**：
   - 第 1 關（A區）：【重心與骨牌】L 型單向底腳與長結合鍵記憶定位
   - 第 2 關（B區）：【單擺】雙柱門型 A 字高架懸吊 60T 雙齒輪重錘跨排打擊
   - 第 3 關（F區）：【槓桿】18cm 雙層架高天橋（下層留車道）＋ 一類蹺蹺板連桿
   - 第 4 關（G區）：【棘輪】★關卡任務一：棘輪配重捲線電梯小球垂直上升 30cm
   - 第 5 關（C➔D）：【重力與斜拋】★關卡任務二：高架俯衝斜坡跳台小球凌空飛越 28cm（≥20cm）
   - 第 6 關（D區）：【軌道與摩擦力】雙邊加高長條護欄與紫擋板防跳球減速滑道
   - 第 7 關（E區）：【向心力與圓周運動】60T 齒輪繞中心單柱 270° 螺旋旋轉下擊
   - 第 8 關（H區）：【作用力與反作用力】碰撞推桿滑塊伸入預備區自動敲下車尾扳機（+2分）
2. **壓軸指定任務（54分）**：
   - 垂直 90° 傘齒傳動窄車身（寬 ≤ 11cm，避開目標區 12 根紅棒）
   - 水平外露 40T 藍色定位齒輪（`7346-W10-C1B`）
   - 捲線器定距 108cm 物理死鎖煞車機構，精準停駐於最深 +3 分區間
3. **智高官方零件圖鑑與 3D 組裝藍圖**：
   - 依據《2026年智高零件目錄訂購單（台中市梧棲區中正國小）》品號與品名精確標註
   - 包含 9 張 1600×960 高清 3D 立體組裝透視圖（點擊可全螢幕燈箱放大檢視）
   - Slide 20 彙整「全作品智高官方積木零件備料總表」
4. **互動教學科技**：
   - Firebase 即時雲端單選投票（模擬裁判現場情境題與標準計分）
   - Emil Kowalski 風格對比滑桿視覺化演示（零擦撞定距車 vs 擦撞失誤車）
   - 支援離線本地預設模式與全螢幕高解析度燈箱檢視
